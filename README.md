# Portfolio de Jonathan Alexander Bender

Portfolio profesional estático, publicado en Netlify.

[Ver portfolio publicado](https://jonathanbender.netlify.app)

## Proyectos presentados

- ACORIA Gestión: aplicación offline-first para comercios.
- Velvet Hogar: sitio comercial y panel administrativo para un emprendimiento familiar.

## Tecnologías del sitio

- HTML semántico.
- CSS responsive.
- Sin dependencias de JavaScript ni formularios que almacenen datos.

## Desarrollo local

Abrir `index.html` en un navegador o iniciar un servidor estático.

## Privacidad

El sitio no publica teléfono, domicilio exacto, documentos, salario ni credenciales. El contacto se realiza mediante LinkedIn.
